SecureChat

Encrypted chat where the server only relays ciphertext and never sees a plaintext message. A Python WebSocket server pairs with a browser client built on the WebCrypto API, where each side generates its own key pair locally. Key agreement uses ECDH P-256, and messages are encrypted end to end with AES-GCM, so the relay has zero knowledge of what it's forwarding.

07

ForkBomber

A small, controlled demonstration of fork-bomb-style process exhaustion on Linux: a bash script that recursively copies and re-executes itself, spawning child processes until a depth condition stops it. A second script benchmarks how the system behaves under that load. The point is using it as a concrete way to study process limits (ulimit) and the mitigations that stop this kind of exhaustion from taking a system down.

BashLinuxProcess limits

FraudGraph
